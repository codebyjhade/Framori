# Contributing to Framori

Thanks for helping make Framori better.

1. Fork the repository and create a focused branch.
2. Make your change without adding a backend or account requirement.
3. Run `npm run check` and test the full frame → photo → edit → ZIP workflow in a modern browser.
4. Open a pull request that explains the user-facing change and includes screenshots for visual updates.

Please keep photo processing private by default, preserve keyboard accessibility, and avoid adding dependencies unless they provide a clear benefit.
